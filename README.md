## 精选项目

### [reverse-skill-pro](https://github.com/Leechuihui/reverse-skill-pro)

逆向工程 / 授权渗透测试 / 安全研究的 **AI Agent 技能路由包（增强版）**

当 AI 客户端（Claude Code、Codex、Cursor、OpenCode 等）面对 APK、二进制、前端加密、CTF 或渗透任务时，先自动路由到正确的方法论，再调用本机工具执行。

**核心能力**

| 能力 | 说明 |
|---|---|
| 自动路由 | 47 条规则（R0–R48），189 条回归基准全绿，48 个领域技能模块 |
| 一键分诊 | 样本魔数识别 → 类型路由 → 工具可用性核对 → triage 报告 |
| 授权硬门 | scope gate：未授权禁止对目标执行任何主动操作 |
| 证据契约 | Evidence → Finding → Path 全链路可追溯 |
| 经验进化 | field-journal 脱敏回写，同类问题不再重复踩坑 |

**覆盖领域**：APK / 二进制 / .NET / JS 逆向、模糊测试、unidbg/Qiling 模拟执行、密码学攻击分析、隐写分析、固件 IoT、CTF 全栈编排（42 个子技能）、渗透工具链、云与容器安全等。
